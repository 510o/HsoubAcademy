# Taskaty
A simple CLI task manager with dates and due-time tracking.

## Features
- Add tasks with title, description, and start/end dates
- List tasks in a readable table with Due In (Today, Tomorrow, Xd overdue)
- Mark tasks as done, remove one/all/completed-only
- Validates date ranges and task numbers
- Stores tasks in JSON (no database needed)
